1สร้างงาน

ผู้ดูแลสร้างงานให้ (หรือกด "ทดลองใช้ฟรี") — ได้ลิงก์งาน + รหัสดาวน์โหลด + รหัสอัปโหลด + รหัส Admin (แก้คะแนนบนเว็บ)

2ดาวน์โหลดไฟล์

เข้าหน้างาน → แท็บ "ไฟล์" → ใส่รหัสดาวน์โหลด ได้ไฟล์ Excel ที่ตั้งค่างานไว้แล้ว (หรือใช้ฟอร์มตัวอย่างด้านบน)

3กรอกออฟไลน์

เปิดใน Excel เครื่องตัวเอง กรอกรายชื่อ ก๊วน และคะแนนรายหลุม — ไม่ต้องต่ออินเทอร์เน็ต

4อัปโหลดกลับ

ใส่รหัสอัปโหลด → เลือกไฟล์ ระบบตรวจไฟล์ให้ก่อน → กดยืนยัน → อันดับ รางวัล ก๊วน จอ TV พร้อมทันที
