GolfPro36 PWA — หน้าเว็บสำหรับ GitHub Pages
1) อัปโหลดทุกไฟล์ในนี้ (ไม่มีโฟลเดอร์ย่อย)ขึ้น repository (ให้ index.html อยู่ชั้นนอกสุด)
2) แก้ config.js บรรทัดเดียว: ใส่ลิงก์ Web App ของ Apps Script (ลงท้ายด้วย /exec)
3) Settings → Pages → Deploy from a branch → main / (root) → Save
หน้าแรก: index.html   หน้างาน: event.html?event=รหัสงาน
